Documentação

Instalação

Veja a página Download. O 1227 precisa do Forge 1.8.9 (11.15.1.2318) e Java 8.

Primeiros passos

  • Abrir o menu: Right Ctrl (dá para trocar no módulo Client ou em Opções › Controles › 1227).
  • Ligar e desligar: clique no card do módulo. Engrenagem ou botão direito abre as configurações.
  • Editar HUD: Client › Edit HUD layout ou /1227 hud. Arraste, role para mudar o tamanho, botão direito para resetar, botão do meio para travar. Os botões Save/Load guardam até 3 layouts.
  • Desempenho: Settings › Performance tem presets de um clique e o limite de partículas.

Configurações e backups

  • Tudo fica em config/1227.json, salvo automaticamente.
  • Cada vez que o jogo abre, uma cópia vai para config/1227-backups/ (as 5 mais recentes). Para restaurar, feche o jogo e copie um backup por cima de 1227.json.
  • Perfis: Settings › Presets (Save/Load profile). Exportar e importar: Settings › Client (Copy config to clipboard / Load config from clipboard).
  • Layouts de HUD: config/1227-hud-layouts.json.

Sons próprios

Coloque arquivos WAV na pasta aberta por Hit Sounds › Open sounds folder e use Reload custom sounds.

Suporte

Abra uma issue no repositório do projeto no GitHub com: versão do 1227, launcher usado, e o arquivo logs/latest.log. Nunca envie senhas ou tokens.
